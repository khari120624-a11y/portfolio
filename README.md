# 🌐 3D Interactive Personal Portfolio - Kukkala Hari Venkat

A modern, interactive 3D personal portfolio web application built with **HTML5**, **Tailwind CSS**, **Three.js**, and **Lucide Icons**.

![Design](https://img.shields.io/badge/Design-3D%20Glassmorphism-cyan.svg)

---

## ✨ Features

- **🎨 3D Interactive Canvas**: Dynamic Three.js background with floating geometric particles responding to mouse movements.
- **💎 Glassmorphism UI**: Premium dark theme with translucent glass cards, vibrant neon gradients (cyan, violet, pink), and smooth blur effects.
- **📱 Responsive Layout**: Fully responsive across mobile, tablet, and desktop devices.
- **⚡ Interactive Sections**:
  - **Hero Section**: Highlighting skills, live links, and direct contact buttons.
  - **About Me**: Professional summary, key strengths, and quick stats.
  - **Skills Matrix**: Categorized tech stack with progress bars (Frontend, Backend, Tools & DevOps).
  - **Projects Showcase**: Interactive project cards with live demos & repository links (including MoodStream).
  - **Experience & Education**: Structured timeline of work and academic background.
  - **Contact Form**: Interactive contact card with direct social links (LinkedIn, GitHub, Email).
- **🚀 One-Click Deployment**: Hosted on GitHub Pages with zero build step required.

---

## 🛠️ Tech Stack

- **Structure**: HTML5
- **Styling**: Tailwind CSS (CDN) + Custom Glassmorphism CSS
- **3D Graphics**: Three.js (r128)
- **Icons**: Lucide Icons
- **Fonts**: Google Fonts (*Inter* & *Fira Code*)

## 🚀 Quick Start / Local Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/khari120624-a11y/portfolio.git
   cd portfolio
   ```

2. **Open in browser**:
   Simply open `index.html` in any modern web browser or start a local server:
   ```bash
   npx serve .
   ```
